# ELA Portfolio Presentation

A colorful and interactive portfolio presentation made with HTML, CSS, and JavaScript.

## Features
- Editable slides (drag elements anywhere)
- Present mode
- Smooth animations
- Upload and insert images/files
- Responsive design
- Keyboard navigation
- Modern colorful UI

## Controls

### Normal Mode
- Drag any text/image box around
- Double click text to edit
- Upload images using the upload buttons
- Use Next/Previous buttons to navigate

### Present Mode
- Click "Present Mode"
- Use:
  - Arrow keys → ←
  - Spacebar
  - On-screen controls

### Editable Features
- Move elements freely
- Resize images
- Edit text directly
- Add your own images/files

## Files
- index.html
- style.css
- script.js

## How To Run
1. Download all files
2. Put them in the same folder
3. Open `index.html`

Enjoy your portfolio presentation!
